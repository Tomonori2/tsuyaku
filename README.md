# 高坂先生の通訳（日本語 ⇔ ベトナム語・タイ語）

スマホを机に置いて向かい合うだけで会話できる、かんたんな通訳アプリです。

**公開ページ**： https://tomonori2.github.io/tsuyaku/

## つかいかた

1. 「設定」から Gemini の APIキーを入れる（[Google AI Studio](https://aistudio.google.com/apikey) で無料）
2. 「🌐 言語」で相手の言語（ベトナム語／タイ語）をえらぶ
3. 下の「🎤 日本語で話す」を押して話す
4. 上側に翻訳が出て、読み上げます
5. 読み上げが終わると**自動で相手側のマイクが開く**ので、そのまま会話が続きます

画面の上半分は180度ひっくり返っています。机に置いて向かい合うと、相手から正しい向きで読めます。

## とくちょう

- **HTML1ファイル**。サーバー不要。開いた瞬間に使えます
- **PWA**。ホーム画面に置けます
- **APIキーは端末の中だけ**に保存されます（BYOK方式）。どこにも送りません
- **定型文は通信なしで使えます**。電波が悪い場所でも最低限のやりとりができます
- 会話の記録も端末の中だけ。全部消すボタンつき

## 注意

翻訳のとき、話した内容は Google（Gemini）に送られます。
**人が特定できる内容や、仕事の中身は話さないでください。** 道案内・手続きの説明・日常会話に使ってください。

## 読み上げの声について

翻訳した文字は出ても、**端末にその言語の読み上げ音声が入っていないと声が出ません。**
「🌐 言語」の画面で 🔊／🔇 を確認できます。🔇 の場合は

　設定 → システム → 言語と入力 → 音声出力（テキスト読み上げ）→ Google音声サービス → 言語のインストール

から、その言語を入れてください。

## 言語を増やすには

`index.html` の先頭にある `LANGS` に1ブロック足すだけです。

```js
zh: {
  name: '中国語', flag: '🇨🇳', native: '中文',
  sr: 'zh-CN', tts: 'zh', bg: '#7f1d1d',
  micIdle: '🎤 请说中文', micOn: '⏹ 正在听…',
  wait: '点击麦克风后说话',
  hint: 'ていねいで自然な話し言葉にしてください。',
  phrases: [ { ja: 'こんにちは', fo: '你好' } ]
}
```
